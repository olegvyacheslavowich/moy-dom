# Мой дом

3D-игра от первого лица в браузере: покупаете заброшенный дом в деревне Берёзовка и за 50 уровней превращаете его в дом мечты. Забор, крыша, скважина, гараж, баня, пруд, интерьер — с выбором материалов и цветов. Поломки, соседская коза и посиделки с Михалычем прилагаются.

**Играть:** https://olegvyacheslavowich.github.io/moy-dom/

На iPhone: откройте ссылку в Safari → «Поделиться» → «На экран „Домой“». Игра сохранится и будет работать без интернета.

Управление: на телефоне левый палец — ходить, правый — осматриваться, кнопка «Делать» — работать. На ПК — WASD, мышь, удерживать E.
