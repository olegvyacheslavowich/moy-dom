МОЙ ДОМ — установка на iPhone (и Android)
==========================================

В папке:
  index.html            — сама игра (3D-движок внутри)
  sw.js                 — service worker: сохраняет игру для офлайна
  manifest.webmanifest  — название и иконка для экрана «Домой»
  *.png                 — иконки

1. Выложить на GitHub Pages
---------------------------
  1) github.com → New repository, например moy-dom, тип Public.
  2) Add file → Upload files → перетащите ВСЕ файлы из этой папки
     (именно файлы, а не саму папку) → Commit changes.
  3) Settings → Pages → Source: Deploy from a branch,
     Branch: main, папка / (root) → Save.
  4) Через 1–2 минуты игра будет по адресу
     https://ВАШ-ЛОГИН.github.io/moy-dom/

   Через git то же самое:
     git init && git add . && git commit -m "Мой дом"
     git branch -M main
     git remote add origin git@github.com:ВАШ-ЛОГИН/moy-dom.git
     git push -u origin main
   и включить Pages, как в шаге 3.

2. Установить на iPhone
-----------------------
  1) Откройте адрес в Safari (именно в Safari).
  2) Дождитесь стартового экрана игры — в этот момент она сохраняется
     для офлайна.
  3) «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
  4) Запускайте с иконки «Мой дом»: на весь экран, без интернета.

  Android: откройте адрес в Chrome → меню ⋮ → «Установить приложение»
  или «Добавить на главный экран».

3. Как обновить игру
--------------------
  Замените index.html новым и в sw.js поменяйте
  VERSION = 'moy-dom-v1' на 'moy-dom-v2'. На телефоне откройте игру
  с интернетом и перезапустите её — подтянется новая версия.
  Прогресс сохраняется.

Важно
-----
  • Прогресс хранится на самом телефоне, в приложении с иконки.
    Сохранения из Safari, из Claude и с компьютера — отдельные.
  • Не удаляйте иконку и не очищайте данные сайта, если не хотите
    потерять прогресс.
